> 在線玩耍地址：<https://knightyun.github.io/maze-game/>

# Features

- 移動端識別重力感應器進行移動，體驗真實的重力感；
- 可自定義調整遊戲難度、地圖大小；
- 隨機生成迷宮地圖，每一次的都不盡相同；
- 桌面端也可通過方向鍵或 `W A S D` 進行移動，加速度固定；
- 地圖較複雜時，可提示迷宮的通關出路；
- 無提示通關最大地圖可觸發遊戲彩蛋🎉，盡情玩耍吧🎮；
